# English Coach PWA — Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fewer bubbles that mix two voices, and «Mis documentos»: the learner's CV and other files, read on the device, whose relevant passages reach «Respuesta» so the AI always has that context.

**Architecture:** (1) The mixed-segment work is a measured tuning round on the existing split (`session.js` `splitIfNeeded`) and the PWA's segmenter settings, decided by `e2e/run.mjs` numbers. (2) Documents are extracted to text on the device (PDF through a vendored pdf.js, DOCX by unzipping with the browser's `DecompressionStream` and reading `word/document.xml`, TXT/MD as text), split into passages, stored in IndexedDB with an on/off switch each, and searched on the device with BM25 against the recent conversation each time «Respuesta» is tapped; the best passages, capped by characters, are added to the reply prompt. Files never leave the device; only the chosen passages go to the chat provider.

**Tech Stack:** as Phases 1–2; plus `pdfjs-dist` 6.4.299 (Apache-2.0) vendored under `vendor/pdfjs/`.

**Spec:** the design proposed in chat on 2026-10-09 and approved on 2026-10-10 ("lo que falta hazlo y realiza la mejor propuesta"): formats PDF, DOCX, TXT, MD (no OCR); text extracted and stored on the device; only relevant passages (~3000 characters) sent per «Respuesta»; «Tu perfil» unchanged and always sent; the report does not use documents; the privacy screen states that chosen passages go to the chat provider; a delete button per document. The mixed-segment criterion of Phase 1 (< 10 % of requests mixing two voices; measured 12–24 %) gets one measured improvement round, the user having asked for "la mejor propuesta".

## Global Constraints

All of `CLAUDE.md`, plus:
- Documents are processed only on the device; the file bytes are never uploaded anywhere; passages go only to the chat provider the learner chose, and the privacy screen and «Mis documentos» say so.
- `vendor/` stays third-party code copied verbatim (pdf.js from the npm tarball of `pdfjs-dist@6.4.299`), listed in `THIRD-PARTY-NOTICES.md` and `docs/ORIGIN.md`; never edited.
- pdf.js runs with its own worker from `vendor/pdfjs/` under the existing CSP (no `unsafe-eval`; `isEvalSupported: false`); if the CSP must change, the change is the narrowest proven one and is stated.
- Limits: at most 10 documents, 2 MB per file, 200 000 characters of text per document; passages added to a reply ≤ 3000 characters.
- Every harness run under `caffeinate -i`, one at a time; nothing reaches a real external API except model and vendor downloads made by the implementer.
- Commit messages: subject, blank line, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Implementers never dispatch subagents.

### Task 1: Fewer mixed bubbles (measured)

**Files:** `session.js`, `session.test.js`, `ui/meeting.js` or `capture.js` (only where segmenter options are passed), `CLAUDE.md`, `README.md`.

Baseline: `caffeinate -i node e2e/run.mjs paulina samantha --condition=room`, `monica daniel`, `paulina monica` (audio-mixed requests, mixed bubbles, word-weighted accuracy, latency p50/p90). Then try, one at a time and measured the same way:
- (a) cut at the middle of the hop where the voice changes (`start_i + hop/2`) instead of `start_i`;
- (b) allow every surviving change of voice in a segment to split it (not only the first), keeping the 2-window minimum run;
- (c) a shorter closing silence for the PWA's single mixed track (`SILENCE_MS` 450 and 550 via the Segmenter's options — never edit `lib/segmenter.js`'s defaults, which are the extension's), checking that sentence bubbles and latency do not degrade.
- [ ] Unit tests for (a) and (b).
- [ ] Adopt the combination with the fewest audio-mixed requests that keeps accuracy ≥ the baseline and p50 latency within +0.3 s; report every measured combination in a table. If none beats the baseline, keep the code unchanged and say so.
- [ ] README and CLAUDE.md state the new numbers and whether the < 10 % criterion is met.
- [ ] Commit `perf(session): fewer bubbles that mix two voices`.
